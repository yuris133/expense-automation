# Инструкция установки: авт. учёт расходов через чеки

Пошаговая установка на Windows с нуля. На каждый шаг — зачем он нужен.
Ориентир по времени: 30–45 минут (большая часть — регистрация бота и сервиса).

## Шаг 1. Python

1. Скачайте Python 3.12+ с [python.org/downloads](https://www.python.org/downloads/).
2. В установщике отметьте **« Add python.exe to PATH »** — без этого команда `python`
   не будет работать из любого окна PowerShell.
3. Проверка (новое окно PowerShell):
   ```powershell
   python --version
   ```
   Должно напечатать, например, `Python 3.12.5`. Если «не является командой» —
   переустановите с отмеченным PATH или перезапустите окно.

## Шаг 2. Библиотеки проекта

В окне PowerShell откройте папку комплекта и выполните:

```powershell
cd "C:\путь\к\папке\комплекта"
pip install -r deploy\requirements.txt
```

Что ставится: `openpyxl` (Excel-отчёты), `pillow` + `opencv` (обработка фото),
`PyMuPDF` (PDF-чеки), `requests` (API), `pytesseract` (OCR), `numpy`.

## Шаг 3. Tesseract OCR (резервный путь распознавания)

Нужен только когда QR-код на чеке не читается (мятый, бликует). Основной путь
работает и без него.

```powershell
winget install UB-Mannheim.TesseractOCR
```

Языковые данные уже в комплекте (`tessdata/rus.traineddata` и др.) — отдельно
скачивать не нужно.

## Шаг 4. Telegram-бот (токен)

1. В Telegram найдите **@BotFather** → команда `/newbot` → придумайте имя →
   бот пришлёт токен вида `123456789:AAE...`.
2. Откройте `config/telegram.json` и впишите его вместо заглушки:
   ```json
   {
    "token": "123456789:AAE...",
    "proxy": ""
   }
   ```
   `"proxy"` оставьте пустым (заполняется только если Telegram заблокирован в сети).
3. Секрет важен: с токеном любой может управлять вашим ботом — не публикуйте его.

## Шаг 5. Токен детализации чеков (API ФНС)

Детализация позиций по фискальным признакам идёт через сервис proverkacheka.com
(неофициальная обёртка API ФНС). Без токена система работает, но позиции
разбирает только по PDF/OCR.

1. Зарегистрируйтесь на [proverkacheka.com](https://proverkacheka.com) (e-mail + пароль).
2. В личном кабинете создайте **API-токен**.
3. Впишите в `config/proverkacheka.json`:
   ```json
   {
     "api_token": "ваш-токен",
     "base_url": "https://proverkacheka.com/api/v1/check/get",
     "note": "Бесплатный тариф: ~15 запросов в сутки."
   }
   ```

## Шаг 6. Первый запуск и проверка

```powershell
# проверка на демо-данных (не трогает ваши чеки)
python src/build_report.py --demo

# реальный запуск бота
python src/telegram_bot.py
```

В чате со своим ботом: `/start` → пришлите фото чека → бот ответит статусом и
положит чек в `receipts/`, пересоберёт отчёт. Проверьте, что появились:

- `data/positions.json` — распознанные позиции;
- `reports/Отчёт_затрат_*.csv` — CSV-снимок;
- папка `reports/` с дашбордом после `/dash`.

Если бот молчит — смотрите `logs/telegram_bot.log` и `logs/bot_console.log`.

## Шаг 7. Кто может отправлять чеки (группы)

Откройте `config/access.json` — там списки групп доступа:

```json
{
  "groups": {
    "main": { "label": "Основная", "users": [], "usernames": [] },
    "office": { "label": "Офис", "users": [], "usernames": [] }
  },
  "unknown_policy": "reject"
}
```

- `users` — числовые **chat_id** участников; `usernames` — ники **без @**.
- Новый человек: отправляет боту любое сообщение → получает отказ с его chat_id →
  вы вписываете этот id в нужную группу → без перезапуска бота доступ работает.
- Каждый видит только свою группу: свои чеки, свои отчёты, свой дашборд.
- Подробно: `Docs/Как добавить чела в группу`.

## Шаг 8. Автозапуск при входе в Windows

Двойной клик по `scripts/setup_autostart.bat` (сам запросит права администратора).
Он создаёт задачу Планировщика `ReceiptsBot`: бот стартует скрыто при входе в
систему и сам переживает падения (петля перезапуска в `run_bot.bat`).

Управление задачей:

```powershell
schtasks /Run   /TN "ReceiptsBot"   # запустить вручную
schtasks /End   /TN "ReceiptsBot"   # остановить
schtasks /Delete /TN "ReceiptsBot" /F  # удалить (перед переездом на сервер — обязательно)
```

Всегда работает **только один** экземпляр бота — два экземпляра делят один канал
Telegram и мешают друг другу.

## Если Telegram недоступен: путь без бота

Чеки можно складывать прямо в папку `receipts/` (вручную или через `ingest.py`
из любого источника — облако, почта):

```powershell
python src/ingest.py --from "C:\Users\...\YandexDisk\Чеки" --move --run
python src/run_pipeline.py
```

Отчёты и дашборд обновятся так же, как от бота.

## Частые проблемы

| Симптом | Причина и что делать |
|---|---|
| `python` не находится | Python не в PATH — переустановка с галочкой PATH |
| Бот молчит при запуске | Неверный токен в `config/telegram.json`; смотреть `logs/` |
| «детализация исчерпана» | Суточный лимит API — до 00:00 МСК; чеки копятся в очередь |
| Позиции пустые, QR есть | Нет токена proverkacheka — шаг 5, или чек ещё в обработке ФНС |
| Две категории спора | Приоритеты в `config/categories.json` (см. «перчатки») |
| Отчёт не виден в Numbers | Даты текстовые `ДД.ММ.ГГГГ` — это сделано специально (см. README) |
